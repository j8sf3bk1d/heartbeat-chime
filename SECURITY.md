# Security

This is a local development preview. Before the repository becomes public, the maintainer should enable GitHub's private vulnerability reporting or provide another private reporting channel here. Until that channel exists, do not post exploit details, credentials, personal backups or private media in public issues.

Do not put API keys, personal audio, backups or private character assets in this repository. See the [release audit](docs/release-audit.md) for dependency and distribution status. Review dependencies and media provenance before release.
