# Security

This is a free, as-is reference project. A private vulnerability-reporting channel has not yet been configured; the maintainer can enable GitHub private vulnerability reporting or provide another channel here. Until that channel exists, do not post exploit details, credentials, personal backups or private media in public issues.

Do not put API keys, personal audio, backups or private character assets in this repository. See the [release audit](docs/release-audit.md) for dependency and distribution status. Review dependencies and media provenance before release.
