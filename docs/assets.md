# Included assets

The synthesized sounds are generated by the app. The included spoken clips were supplied by the project owner and generated using ElevenLabs; the owner intends these clips to be shared with the free reference project, subject to applicable provider terms. The [150 recordings and their line/expression manifest](../src/assets/voices/laura/manifest.json) are included; credentials, provider voice models and generation receipts are not. See the [character-to-voice workflow](character-creator/emotion-voice-workflow.md). Heartbeat’s original character expression art and app icon are included with the owner’s permission. Fan-inspired packs are not included. Third-party license and generated-asset terms remain documented maintenance considerations.

The four bundled themed sound-effect collections were generated using ElevenLabs SFX v3 from original project prompts and selected by the owner. Each contains cues suggested for 1, 5, 15 and 60 minutes; the train-door cue has a locally amplified WAV derivative. Keep provider provenance and applicable account terms in view when redistributing.
