# Included assets

The synthesized sounds are generated by the app. The included spoken clips were supplied by the project owner and generated using ElevenLabs; confirm the relevant account terms, rights and distribution permission for the actual voice and clips before release. Credentials and generation receipts are not included. Heartbeat’s original character expression art and app icon are included with the owner’s permission. Fan-inspired packs are not included. Third-party licenses and generated-asset rights still need a release audit.

The four bundled themed sound-effect collections were generated using ElevenLabs SFX v3 from original project prompts and selected by the owner. Each contains cues suggested for 1, 5, 15 and 60 minutes; the train-door cue has a locally amplified WAV derivative. Review provider output and applicable account terms before redistribution, along with the other release checks above.
