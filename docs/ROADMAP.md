# Development roadmap

This is a local candidate; public release is not yet approved or complete.

- Verify desktop isolation, imported character switching, audio, backup/restore, startup and packaging on target platforms.
- Review source and dependency provenance, code license, third-party licenses and distribution rights for every included voice and other asset. Scan for secrets and personal data before publishing. Add installation and support guidance.
- Keep the existing voice pack and synthesized chimes; consider an additional brighter voice pack with previews and clear tone choices.
- Explore optional, auditionable sound-effect packs: machine shop/factory, public library, Japanese train station and restaurant. Evaluate sound design, volume, licensing and ElevenLabs generation separately before bundling. Packs and routine presets should preview changes and preserve existing user assignments.
- Develop character-specific voice-pack metadata and creation flows; character visuals, sound selection and assignments remain independently switchable. See character-creator/voice-packs.md.
- Expand character animation and lab coverage with purpose-made distributable full-expression fixtures; the included example is a still image only.
- Choose a public license and repository name, then configure the remote only when the owner supplies it. Do not publish automatically.
